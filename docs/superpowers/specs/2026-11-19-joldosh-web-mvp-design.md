# Жолдош — чыныгы веб-версия (MVP) дизайны

Статус: **ээси бекитти** · 2026-11-19

## 1. Максат жана эмне үчүн
Азыркы демо (`app/index.html`) бардык маалыматты ар бир колдонуучунун өз телефонунда сактайт, колдонуучулар бири-бирин көрбөйт.
Максат: ошол эле колдонмону **чыныгы сайт** кылуу. Бир адам жарыялаган посылканы же сапарды башка адам өз телефонунан көрөт, айдоочу алып кетет, жөнөтүүчү аны картадан көзөмөлдөйт.

Ээсинин эки негизги талабы:
- **Акысыз:** колдонуучуларга акысыз жана иштетүү да акысыз (акысыз пландар). Төлөнүүчү бир гана нерсе — SMS.
- **Ишеним:** кымбат посылканы алган айдоочу аны жеткирбей качып кетсе, ал адамды **сөзсүз таба тургандай** болушу керек.

## 2. Максаттар
1. Каттоо **SMS код** менен (милдеттүү).
2. Каттоодо **жайгашкан жерге уруксат** суралат (браузер аркылуу).
3. Попутка: сапар жарыялоо, издөө, чыпка, орун брондоо.
4. Посылка заказы: сүрөт, дарек, алуучу, сунушталган баа, **жарыяланган баалуулугу (сом)**; каалаган ылайыктуу айдоочу алат.
5. Айдоочуну текшерүү: паспорт/ID, ПИН, айдоочулук күбөлүк, селфи, машина (мамлекеттик номери менен), **2 кепил адам** (номерлери SMS менен ырасталат).
6. Жол көзөмөлү: айдоочунун GPS изи посылканы алгандан жеткиргенге чейин серверде сакталат; жөнөтүүчү картадан реалдуу убакытта көрөт.
7. Далил чынжыры: алууда посылканын сүрөтү; жеткирүүдө алуучунун **4 сандуу коду**.
8. Кымбат посылкага чек: жарыяланган баалуулугу чектен ашса, аны тажрыйбалуу жана рейтинги жогору айдоочулар гана ала алат.
9. Чат (колдонмо ичинде), пикирлер, билдирүүлөр.
10. Колдоо кызматы жана **оператор панели** (чыныгы логин, бардык колдонуучулардын арыздары бир жерде), айдоочуну бөгөттөө, «укук коргоо органдары үчүн маалымат топтому».
11. KG/RU, азыркы дизайн системасы (`design-system/joldosh/MASTER.md`), бирюза бренд.

## 2a. Кошумча талаптар (ээси, 2026-11-21) — 2-этапта
- Шаар чиптери **жөнөө шаары** боюнча чыпкалайт: Ош тандалса — Оштон чыга турган посылкалар/сапарлар гана.
- **Жүк (Портер):** заказдын «Жүк» өлчөмү (1,5 т чейин); машинанын түрү `car` / `porter`; жүк заказын «Портер» машинасы бар айдоочу гана алат; башкы бетте «Жүк» бөлүмү.
- Айылдар жана Бишкектин ичиндеги жерлер (`web/src/ui/places.js`), тизмеде жок жерди колдонуучу өзү жаза алат.

## 3. Максат эмес (ушул версияда жок)
- Төлөм, капчык, лимит — өчүрүлөт (кийин кошулат).
- Android/iOS колдонмосу — кийин; азыр сайт (PWA: телефондун башкы экранына кошсо болот).
- Телефон байланыштарын окуу — **жасалбайт** (мыйзам, колдонмо дүкөндөрүнүн эрежелери, натыйжасыздыгы). Ордуна кепил адамдар.
- Фондогу GPS (экран өчкөндө) — сайтта мүмкүн эмес; ордуна айдоочу жолдо экранын күйгүзүп турат (Wake Lock).
- Push-билдирүүлөр — кийин (азыр колдонмо ичинде + маанилүү окуяларда SMS эмес).

## 4. Анти-максаттар (иштесе да ийгиликсиздик)
- Паспорт сүрөттөрү же GPS изи башка колдонуучуларга ачык көрүнүп калса.
- Айдоочу коддун ордуна «жеткирилди» деп өзү белгилей алса.
- SMS чыгымы көзөмөлсүз өссө (бот/спам каттоолор).
- Сайт демодон жайыраак же татаалыраак болуп калса.

## 5. Чектөөлөр
- Supabase Free: маалымат базасы, Auth, Storage, Realtime, Edge Functions — акысыз пландын көлөмү чектелүү (MVP үчүн жетиштүү).
- SMS: Supabase Phone Auth + **Nikita.kg** (ээси тандады). Supabase'тин «Send SMS hook» функциясы эдж-функцияны чакырат, ал эдж-функция кодду Nikita.kg API аркылуу жөнөтөт. Ээси Nikita.kg'де аккаунт ачат: логин/сырсөз, каттоодон өткөн жөнөтүүчү аты (мисалы, «Joldosh») жана баланс.
- Хостинг: Cloudflare Pages же GitHub Pages (акысыз, `*.pages.dev` дареги).
- Карта: Leaflet + OpenStreetMap плиткалары (аз трафикте акысыз; көбөйсө MapLibre + акысыз провайдер).
- Мыйзам: Кыргызстандын «Жеке маалыматтар жөнүндө» мыйзамы — колдонуучунун макулдугу, паспорт маалыматы жабык сакталат.

## 6. Варианттар (курулуш жолу)
| Вариант | Артыкчылыгы | Кемчилиги |
|---|---|---|
| **A. Supabase + акысыз хостинг** ✅ тандалды | Акысыз; SQL (татаал издөө оңой); Auth, сактагыч, реалдуу убакыт даяр; SMS шлюзу туташат; кийин мобилдик колдонмо ошол эле серверди колдонот | Акысыз пландын көлөмү чектелүү |
| B. Firebase | Окшош мүмкүнчүлүктөр | SQL эмес — «Ошко, эртең, посылка алган» сыяктуу издөөлөр ыңгайсыз |
| C. Өзүбүздүн Node.js сервер (Render free) | Толук көзөмөл | Иш эки эсе көп; акысыз сервер «уктайт» (30–50 с күтүү) |

Тандоо: **A** (SMS — Nikita.kg) — сунуштадым, ээси «курулушту» мага ишенип берди. Бул менин чечимим.

## 7. Ээси чечкендер
- Сайт, акысыз, SMS милдеттүү, жайгашкан жерге уруксат.
- Байланыштардын ордуна: текшерүү + кепил адамдар + GPS изи + далил чынжыры + кымбат посылкага чек.

## 8. Архитектура (менин чечимдерим, курулушчу тактай алат)
- **Фронтенд:** Vite + жөнөкөй JavaScript модулдары. Азыркы экрандар, CSS токендери жана тексттер (KG/RU) модулдарга бөлүнүп көчүрүлөт. Фреймворк жок (азыркы код ошондой, жеңил). PWA манифести.
- **Сервер:** Supabase (Postgres + Row Level Security), Edge Functions (Deno) — SMS hook, жеткирүү кодун текшерүү, кепилди ырастоо.
- **Сактагыч:** `parcels` (жалпы окуу — посылка сүрөттөрү), `avatars` (жалпы), `kyc` (жабык — паспорт, селфи; администраторлор гана).
- **Реалдуу убакыт:** чат, заказдын статусу, айдоочунун жайгашкан жери.

### Маалымат модели (негизги таблицалар)
`profiles` (id=auth.users, аты, телефон, тил, сүрөт, роль: user/admin/operator, бөгөттөлгөнбү)
`driver_verifications` (статус: none/pending/verified/rejected, паспорт, ПИН, айдоочулук, сүрөт жолдору, ким текшерди)
`guarantors` (айдоочу, аты, телефон, ырасталганбы)
`cars` (айдоочу, марка, модель, жыл, түс, руль, мамлекеттик номери)
`trips` (айдоочу, кайдан, кайда, күн/убакыт, орун, баа, посылка алабы, посылка баасы, статус)
`bookings` (сапар, жүргүнчү, орун саны, статус)
`parcel_orders` (жөнөтүүчү, кайдан/кайда, даректер, сүрөт, өлчөм, сунушталган баа, **жарыяланган баалуулугу**, алуучу, айдоочу, статус: open/accepted/onway/delivered/cancelled/disputed, **жеткирүү кодунун хэши**, алуудагы сүрөт, убакыттар)
`location_points` (заказ, айдоочу, lat, lng, убакыт) — посылка жолдо турганда гана
`messages` (тред: order/trip/ticket, ким, текст, убакыт)
`reviews`, `notifications`, `tickets` (себеби, заказ, статус)

### Коопсуздук эрежелери (RLS)
- Паспорт/селфи/ПИН/кепилдер: ээси жана admin/operator гана.
- GPS изи: заказдын жөнөтүүчүсү, айдоочусу жана admin/operator гана.
- Телефон номери: сапардын/заказдын катышуучуларына гана.
- Заказды `delivered` кылуу: эдж-функция гана, алуучунун туура коду менен (айдоочу өзү белгилей албайт).
- Кымбат посылка: `parcel_orders.declared_value > VALUE_LIMIT` (**5000 сом**, ээси бекитти) болсо, аны тажрыйбалуу айдоочу гана ала алат. Тажрыйбалуу деген: кеминде `N` жеткирүүсү бар жана рейтинги `R` же жогору.

### SMS чыгымын көзөмөлдөө
Supabase Auth лимиттери (бир номерге/IP'ге минутасына), Cloudflare Turnstile (акысыз капча) кирүү формасында.

### Негизги агым (посылка)
1. Жөнөтүүчү: сүрөт, даректер, алуучу, баа, баалуулугу → `open`.
2. Ылайыктуу айдоочу «Алам» → `accepted`.
3. Айдоочу посылканы алып, сүрөткө тартат → `onway`. GPS жөнөтүү башталат (30 сек сайын, экран күйүк).
4. Жөнөтүүчү алуучуга 4 сандуу кодду берет (бөлүшүү баскычы).
5. Айдоочу алуучудан кодду алып киргизет → эдж-функция текшерет → `delivered`, GPS токтойт.
6. Көйгөй болсо → колдонуучу арыз берет → оператор айдоочунун толук маалыматын, кепилдерин жана GPS изин көрөт → бөгөттөйт / «маалымат топтомун» экспорттойт.

## 9. Ээси аткара турган иштер
- Supabase аккаунту (акысыз) — долбоор түзүү.
- SMS шлюзу: **Nikita.kg** — аккаунт, жөнөтүүчү атын (альфа-аты) каттоо жана баланс.
- Хостинг аккаунту (Cloudflare же GitHub Pages) — акысыз.
- Ачкычтар чатка жазылбайт, коопсуз форма аркылуу берилет.

## 9a. Курулушчунун текшерүүсүнөн кийин кабыл алынган чечимдер (менин чечимдерим — ээси оңдой алат)
- Тажрыйбалуу айдоочу: кеминде **5** жеткирүү жана рейтинги **4.5** же жогору (`N=5`, `R=4.5`, конфигурацияда).
- Айдоочуну оператор панелинен **кол менен** текшерет: документтерди карап «Ырастоо / Четке кагуу» басат. Автоматтык текшерүү жок.
- Биринчи администраторду ээси Supabase'те `profiles.role = 'admin'` деп өзү белгилейт. Андан кийин операторлорду панелден кошот.
- Алуучунун коду: жөнөтүүчүгө көрсөтүлөт, ал «Бөлүшүү» баскычы менен WhatsApp/Telegram аркылуу алуучуга жөнөтөт. SMS менен жөнөтүү чыгымдуу болгондуктан, кийинкиге калтырылды.
- Кепилдердин номерлерин ырастоо: бир айдоочуга дагы 2 SMS кетет (чыгымга кирет).
- GPS изи 90 күн сакталат, андан кийин өчүрүлөт (талаш ачык болсо — сакталат).
- Демо (`app/index.html`) ошол бойдон калат. Жаңы сайт өзүнчө папкада: `web/` (фронтенд) жана `supabase/` (миграциялар, эдж-функциялар).
- Дарек: акысыз `*.pages.dev` (кийин домен кошсо болот).

## 10. Курулушчуга калтырылгандар
Папкалардын түзүлүшү, модулдарга бөлүү тартиби, миграциялардын аталышы, UI'дин майда-чүйдөсү (дизайн системасына ылайык), тесттер (Vitest + Playwright), GPS жөнөтүү жыштыгы (30 сек сунуш).

## 11. Ачык суроолор (ээсине)
Азырынча жок. Эскертүү: Nikita.kg аккаунту тестовый режимде — API SMS профилдеги номерге гана жөнөтөт; чыныгы ишке киргизүүдөн мурун ээси жөнөтүүчү атын бекиттирип (names@nikita.kg), келишим түзөт.
