# Жолдош — попутки по Кыргызстану

Мобильное веб‑приложение для поиска попутных поездок (демо‑прототип).

Откройте `app/index.html` в браузере телефона или компьютера.

Возможности:
- поиск поездок (откуда/куда, дата, количество мест, запрос всем водителям);
- список поездок и карточка поездки, бронирование и отмена брони;
- звонок / WhatsApp водителю;
- создание поездки водителем, добавление автомобиля (марка, модель, год, госномер, руль, цвет);
- профиль, личные данные, рейтинг и отзывы;
- уведомления.

Данные хранятся в localStorage на устройстве — для реального запуска нужен сервер (база данных, SMS‑вход).
