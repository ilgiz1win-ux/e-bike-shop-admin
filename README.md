# Жолдош — попутки и посылки по Кыргызстану

Мобильное веб‑приложение для попутных поездок и доставки посылок (демо‑прототип). Интерфейс на кыргызском и русском (переключатель KG / RU).

Откройте `app/index.html` в браузере телефона или компьютера.

Возможности:
- вход по номеру телефона с SMS‑кодом (в демо код показывается на экране);
- главная лента объявлений (попутки и посылки) с фильтрами: тип, откуда, куда (быстрые чипы городов), дата;
- подробный поиск попуток и водителей для посылок; запрос всем водителям по маршруту;
- бронирование мест и отправка посылок (размер, получатель), отметка «Доставлено» у водителя;
- регистрация водителя с паспортными данными (ID‑карта / паспорт, ПИН, дата и орган выдачи, вод. удостоверение, 3 фото);
- создание поездки водителем (с приёмом посылок или без), автомобиль;
- профиль, рейтинг и отзывы, уведомления.

Данные хранятся в localStorage на устройстве. Для реального запуска нужен сервер: база данных, SMS‑шлюз, проверка документов модератором.
